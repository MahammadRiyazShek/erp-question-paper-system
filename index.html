About this ERP System

A full-fledged working website for question paper access for students in University. Implements all four CRUD operations (Create, Read, Update, Delete).

Tech Stack

  • Frontend: AngularJS 1.8 framework with two-way binding, directives, services
  • Backend: Oracle SQL (PL/SQL stored procedures for CRUD)
  • Schema: QUESTION_PAPERS(id PK, course, code, semester, year, description, file_url, created_at)

Features

  • Student-facing paper browsing with search & filters
  • Admin CRUD dashboard for paper management
  • Role-based access (Student / Admin / Faculty)
  • Real-time stats dashboard
